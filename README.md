# crop-suitability-classification
Machine learning based crop suitability classification system using soil and environmental conditions.

This project is a machine learning based crop recommendation system.

## Project Overview

The system predicts a suitable crop using soil and environmental conditions such as nitrogen, phosphorus, potassium, temperature, humidity, pH and rainfall.

## Models Used

- K-Nearest Neighbors
- Decision Tree
- Logistic Regression

## Final Model

Decision Tree

## Application

The trained model is integrated with a Streamlit application where users can enter the required values and receive a crop recommendation.

## Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit
